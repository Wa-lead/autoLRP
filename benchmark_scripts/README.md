# Attribution Faithfulness Benchmark (clean)

MoRF/LeRF (text + vision) and TGS/TPS (EQA), comparing autoLRP against IG,
GradSHAP, AttnLRP. Raw output only — no reductions.

## Verified locally
`test_local_arch.py` runs the real adapters + scorers against tiny
random-weight HF models (real LLaMA RMSNorm/GQA, BERT QA, ViT) and asserts the
pipeline executes with well-formed output. 9/9 components pass. This proves the
machinery runs; it does NOT reproduce paper numbers (untrained tiny models).

    PYTHONPATH=/path/to/autoLRP python test_local_arch.py

## Architecture (one job per file)
- `scorers.py`     — MoRF/LeRF + TGS/TPS. The ONLY place scoring lives. Tested.
- `adapters.py`    — one attribute() per method. The only method-specific code.
- `model_setup.py` — per-model wiring (embed paths, T5 decoder, NaN-trap).
- `run_morf_lerf.py` / `run_tgs_tps.py` — thin runners, save raw.
- `aggregate.py`   — collect raw results.
- `smoke_test.py`  — 2-example check per (task,method) on the REAL models.

## Run order (on a GPU box with real weights)
1. Smoke each pair you intend to run:
       python smoke_test.py --task imdb --method autolrp --autolrp-repo PATH
2. Full runs (save raw):
       python run_morf_lerf.py --task imdb --method autolrp --n 1000 --autolrp-repo PATH
       python run_morf_lerf.py --task vit  --method autolrp --n 100  --autolrp-repo PATH
       python run_tgs_tps.py  --task bert --method autolrp --n 1000 --autolrp-repo PATH
   Baselines: --method ig|gradshap|attnlrp.
3. Aggregate:
       python aggregate.py --results-dir results
